# Recordings - Cybersecurity B1

The spoken audio for the course at
<https://learnactively.com/cybersecurity/b1>. Generated by
`tools/build-audio.py` in the course project and published here by
`tools/publish-media.py`; nothing here is edited by hand.

It lives apart from the site so that the site's repository carries only
text. The course fetches these files from this repository's own GitHub
Pages site. Each file is named by a hash of the words and the voice that
make it, so a URL can never come to mean a different recording.
